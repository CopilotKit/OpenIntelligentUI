# Open Generative UI — interactive implementation

Read the master playbook for routing and the standalone assemble_document contract.
This server returns HTML text with theme CSS and legacy postMessage helpers. It
has no injected importmap or Websandbox connection. generateSandboxedUi in the web
app uses a separate streaming contract; do not mix the two environments.

## Structure

Supply html with styles and scripts suitable for an isolated iframe. Use theme
variables such as --color-text-primary, --color-text-secondary,
--color-background-secondary, --color-border-tertiary, and --border-radius-md.
Keep useful content visible before scripts load. Include headings, assumptions,
sources, units, and instructions where they help a self-contained answer.

Use responsive grids, wrapping controls, and viewBox SVG. For charts, bound the
container height and resize with its container. Resolve theme colors for canvas
using getComputedStyle. Provide a textual summary or accessible table alongside
canvas. Respect reduced motion; pause animation and keep one loop per simulation.
Use real Three.js geometry and responsive camera controls for 3D when it is useful.
Dispose resources on teardown and display initialization failures visibly.

## Numeric tools

For input[type=number], read valueAsNumber, reject non-finite values and out-of-range
inputs, and check denominators. min/max alone do not validate user typing. Show a
clear error and mark invalid fields; avoid stale output. Preserve internal precision
and format displayed values with Intl.NumberFormat. Include units, assumptions,
reset behavior, and the formula used. Never eval a user-supplied expression.

## Controls

Use native buttons with clear labels, explicit input labels, visible keyboard focus,
and role=status for feedback. Forms must prevent unwanted navigation; non-submit
buttons use type=button. Use buttons inside sortable table headers. Sorting and
filtering should use the same state and preserve one another. Insert data using
textContent rather than interpolating values into HTML. Interactive tabs require
proper keyboard/ARIA behavior; simple toggle buttons can use aria-pressed instead.

## Libraries and network

Allowed script CDN origins are cdnjs.cloudflare.com, esm.sh, cdn.jsdelivr.net,
and unpkg.com. Load pinned library URLs and handle errors; bare imports require an
explicit importmap, which this renderer does not inject. Module scripts may use
imports; classic scripts cannot use top-level await. Styles are inline under the
current CSP; do not assume arbitrary stylesheet or API URLs work. Do not rely on
cookies, localStorage, or parent DOM in a properly isolated sandbox.

## Follow-up actions

Use sendPrompt(text) only when a consuming host explicitly supports the legacy
bridge. It posts a request without delivery acknowledgement. Do not claim success
or substitute this helper for the web app's validated
Websandbox.connection.remote.sendPrompt({ text }). Include selected values only
following a deliberate user click. Local controls must not send chat messages.
The standalone host must validate requests; never send credentials or secrets.

## Evidence

Show user data or genuine retrieved evidence. Explicitly label sample metrics,
comparison weights, and simulation assumptions. No fabricated current weather,
market prices, business records, or citations. A renderer supplies no live data.
